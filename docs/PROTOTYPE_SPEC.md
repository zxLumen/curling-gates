# 10 秒原型 · 可执行规格 v0.6

> 目标：验证「吃门 → 变大/分裂 → 清屏爆分」是否好玩。
> 范围：单机、3 壶、3 排门、30 个钉子、无养成、无联网、无广告。

## 1. 验收标准

连续玩 10 局后，满足以下任意 2 条即可进入下一阶段：

- [ ] 主动想再来一局
- [ ] 能说出至少一次“这球真爽”的瞬间
- [ ] 会尝试不同的门组合（变大 vs 分裂）
- [ ] 能感知到「瞄准」而不是纯看动画

如果 10 局后不想再玩，先调手感，不要加内容。

### 4.2 触发规则

- 壶中心从下方穿过该排 y 时判定
- 命中条件：`abs(stone.x - gate.x) <= gate.w / 2`
- 每排每个门每壶只能触发一次
- 完美判定：`abs(stone.x - gate.x) <= gate.w * 0.15`，额外 `+0.5x` 门倍率
- 分裂后只有第一个穿过门的子壶触发，避免指数爆炸

### 4.3 数值

| 类型 | 效果 |
|---|---|
| sizeUp | `r *= 1.45`，上限 3×R0 |
| split | 2 个子壶，`r *= 0.72`，速度 ×0.95，左右 ±0.18 rad |
| speedUp | `speed *= 1.3`，上限 13 |
| mult | `gateMult += 1`，上限 5 |
| magnet | 4 秒内吸附 2.6m 内钉子，拉力 3.2 m/s² |
| pierce | `pierce += 3`，撞钉不减速 |
| shrink | `r *= 0.72`，最低 0.55×R0；`gateMult += 1` |
| sticky | 摩擦 ×1.45 |

## 5. 钉子与大本营

- **30 个钉子**：7 排菱形（3/4/5/6/5/4/3），间距 0.55m
- 钉子被撞后飞走并淡出；飞出的钉子不参与物理碰撞
- **钉子连锁**：命中点以 0.66m 为半径触发最多两代连锁，制造“一壶清一片”的反馈
- 连锁钉子只计分、不消耗穿透、不衰减冰壶速度
- 大本营计分：距离中心 `<0.35` → 250；`<1.05` → 120；`<1.83` → 60
- 大本营分在壶停稳后结算

## 6. 计分

```text
单钉 = 15 × 当前 totalMult
大本营 = 基础分 × 本壶峰值倍率
totalMult = min(20, 1 + gateMult + comboMult + chainMult)
comboMult = min(6, combo × 0.1)
chainMult = min(2, max(0, gateChain - 1) × 0.5)
清屏奖励 = 800 × 本壶峰值倍率
```

**门链：**

- 连续命中门：`gateChain +1`
- MISS：`gateChain = 0`，飘字“门链断”
- 每多一层门链 +0.5x，最多 +2x

**目标与星级：**

| 星级 | 分数 |
|---|---|
| 1 星 | 3,000 |
| 2 星 | 6,000 |
| 3 星 | 10,000 |

- HUD 显示目标分与进度条
- 结算显示星级、最高分、最高倍率、最高连击、最高门链、每壶得分
- 未达标显示“距离目标还差 X 分”

## 7. 控制

| 操作 | 实现 |
|---|---|
| 蓄力 | `pointerdown` 开始；`chargeTime += dt`；`power` 在 0→1→0 之间往返，周期 2×1.05s |
| 力度条 | 球旁竖向渐变胶囊：蓝 → 绿 → 红；刻度线；满力红色 MAX |
| 瞄准 | 按住时左右拖动；`angle = clamp(-(curX - startX) / 110 * 0.55, -0.55, 0.55)` |
| 投掷 | `pointerup` 且 `power >= 0.08`；低于 0.08 或极快点击取消 |
| 满力 | 到顶后回落；不自动投，松手按当前力度投 |
| 选球 | 爬塔模式底部 4 个冰球按钮；瞄准时切换，滑行时锁定 |
| 旋转 | 底部按钮 -1 / 0 / +1；**localStorage 记忆**，新球/重开/刷新保持 |
| 擦冰 | 滑行中按住画面；体力 2.2s，恢复 1.3s |
| 重开 | 右上角「↻ 重开」/ `R`，立即重置本局 |
| 键盘 | `A/D` 旋转，`S` 直，`Space` 擦冰，`R` 重开，`M` 静音 |

## 8. 流程

```
menu → aim → slide → between → (下一壶 | result)
```

| 阶段 | 行为 |
|---|---|
| menu | 模式选择（爽快 / 爬塔）、静态棋盘 |
| aim | 按住蓄力，左右拖动瞄准，显示轨迹与力度条 |
| slide | 物理模拟，可擦冰 |
| between | 结算本壶，1.0s 后下一壶；点击可跳过 |
| result | 显示总分/星级/最高分，再来一局 |

- 每壶重置：壶、钉子、门、连击、门倍率、体力
- 爬塔模式见 [`TOWER_MODE.md`](TOWER_MODE.md)

- 每壶重置：壶、钉子、门、连击、门倍率、体力
- 不重置：总分、最高分、每壶得分记录

## 11. 已知取舍

- 原型不做真实冰壶 4 人队/10 局制
- 原型不做实时 PvP
- 原型不做内购
- 原型美术为程序化占位
- 原型音效为合成音，最终替换

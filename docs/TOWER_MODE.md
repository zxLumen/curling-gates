# 爬塔模式 · 调研与设计（冰球版）

> 分支：`feature/tower-mode`
> 基线：`master` / `v0.3-baseline`，随时可回退（见 `ROLLBACK.md`）
> 本版已把“石头合并”改成“不同冰球 + 单球强化”，参考《哥布林弹球 Peglin》。

## 1. 参考玩法

| 游戏/类型 | 核心机制 | 可借鉴点 |
|---|---|---|
| **哥布林弹球 Peglin** | 收集不同弹珠，每颗弹珠有独特效果；弹珠撞钉子造成伤害；关卡间强化弹珠/拿遗物 | **不同球 = 不同 build**；单球强化；每发选择用哪颗球 |
| **魔塔 / Magic Tower** | 攻击 > 防御才能击杀 | 层数门槛清晰 |
| **Random Dice: Defense** | 合并骰子提升攻击，抵御波次 | 短波次、成长可见 |
| **Merge Defense 系列** | 合并单位/炮塔，守住波次 | 合并/强化后战力立刻变化 |
| **《赵云与阿斗》** | 合并 + 塔防，抖音畅销 | 合并+塔防在抖音可行 |
| **《矮人爬爬塔》** | 点击/合并军队，向上爬塔 | 爬塔目标感 |

### 调研结论

1. **Peglin 的核心不是“合并”，而是“每颗球不一样”**：球的特性决定这一发怎么打。
2. **强化要落到具体球上**：玩家要能说“我这颗旋弧球升到 3 级了”，而不是“我有一堆石头”。
3. **层数门槛要清晰**：伤害 / 防御一眼可见。
4. **短局 + 快速重试**：3 心，失败保留 build。
5. **不要同时做两套复杂操作**：冰壶投掷是操作核心，爬塔只做“选球/强化”决策。

## 2. 核心循环

```
选择爬塔（初始只有 1 颗标准球）
  → 第 N 层：怪物防御 DEF，门/钉子随机布局
  → 3 壶投掷，每壶可选一颗已拥有的冰球
  → 伤害 = 本层得分 × 该冰球攻击倍率
  → 伤害 ≥ DEF？立即突破，不再等剩余壶数
      是：三选一（新冰球 / 强化现有冰球 / 回心）→ 下一层
      否：3 壶用完仍不足 → 失去 1 心 → 重试本层（保留冰球）
  → 3 心用完，本次爬塔结束
```

**和爽快模式的关系：**

- 爽快模式：同一颗标准球，3 壶冲 6,000 / 10,000。
- 爬塔模式：初始 1 颗标准球，逐层收集/强化，最多 4 种冰球。
- 共用物理、门、钉子、计分；只在外层加“层数 / 防御 / 选球 / 强化”。

## 3. 冰球

### 3.1 四种冰球（MVP）

| 冰球 | 半径 | 初始攻击 | 特性 |
|---|---|---|---|
| **标准球** | 1.0×R0 | +0% | 初始球，均衡稳定 |
| **巨力球** | 1.3×R0 | +5% | 更大更重，撞击更强 |
| **旋弧球** | 0.95×R0 | +10% | 旋弧 ×1.6，适合绕门 |
| **分裂球** | 0.9×R0 | +15% | 首次穿过门时分裂成两颗 |

> R0 = 0.16m。每升 1 级，半径 +5%，攻击 +18%。
> 初始只有标准球；其余通过层间三选一获得。

### 3.2 层间三选一

- 每层突破后，从 **3 个随机选项**里选 1 个：
  - **新冰球**：获得未拥有的球，Lv.1。
  - **强化现有冰球**：指定球 Lv+1（最高 Lv.5）。
  - **回心**：+1 心（球池没有可选项时保底）。
- 只有选完才能进入下一层。
- 没有石头、没有合并；球本身就是 build。
- 目标：让玩家形成“我这局主升旋弧球/分裂球”的 build 感。

### 3.3 选球

- 底部一排冰球按钮，数量从 1 到 4，显示名称 + 等级。
- 仅在瞄准阶段可切换；滑行/结算时锁定。
- 切换后，瞄准中的冰球半径、颜色、旋弧倍率立即变化。
- 获得/强化后自动选中该球。

## 4. 层数数值

| 层 | 怪物防御 | 玩家目标 |
|---|---|---|
| 1 | 800 | 极低难度；1 颗标准球，1~2 壶通常可过 |
| 2 | 1,200 | 拿到第 2 颗球或强化后 |
| 3 | 1,800 | 需要选对球/门链 |
| 4 | 2,700 | 需要 2~3 次补给 |
| 5 | 4,050 | 第一次小考 |
| 6+ | ×1.5 / 层 | 无尽爬塔 |

> 前 3 层尽量低难度，先让玩家体验“选球/强化”的成长，再逐步加门槛。

## 5. 失败与重试

- 每层 3 心。
- 伤害 < DEF：失去 1 心，**保留所有冰球等级**，重试本层。
- 0 心：本次爬塔结束，显示到达层数 + 最高层数。
- 暂不做广告复活；后续可加。

## 6. UI

### 6.1 模式选择

```
[ 爽快模式 ]   3 壶冲高分
[ 爬塔模式 ]   选球 + 强化，逐层打防御
```

### 6.2 爬塔 HUD

- 第 N 层
- 怪物防御 DEF（大本营上方也有 DEF 徽章）
- 伤害进度条：`当前伤害 / DEF`
- 达标立即过关，不再等剩余壶数
- 心数 `❤❤❤`
- 当前冰球攻击加成

### 6.3 底部选球条

```
[标准 Lv.1] [巨力 Lv.1] [旋弧 Lv.2] [分裂 Lv.1]
```

- 初始只有 1 个「标准」；之后逐层增加。
- 选中球有高亮边框（颜色对应球色）。
- 滑行时按钮禁用。

### 6.4 层间界面

```
第 N 层突破！

伤害 956 / DEF 800

[标准球 Lv.1 → Lv.2]   [旋弧球 · 新冰球]
[分裂球 · 新冰球]

选择 1 个：新冰球 / 强化现有冰球 / 回心
（选完才能进入下一层）

[ 进入第 N+1 层 ]
```

### 6.5 每层随机布局

- 每层重新生成 2~3 排门：类型、位置、宽度随机。
- 第 1 排固定为两个成长门（变大/分裂），保证前期能吃到。
- 第 2/3 排随层数增加减益概率、缩小门宽。
- 30 个钉子也做随机抖动/整体偏移，避免每层完全一样。
- 重试本层时保持同一布局，避免“换图刷分”。

## 7. MVP 范围

- 爬塔模式独立入口，爽快模式不变。
- 初始 1 颗标准球，最多收集 4 种冰球。
- 每层三选一：新冰球 / 强化现有球 / 回心。
- 每层随机门+钉子布局，重试保持布局。
- 伤害达标立即过关，不等待剩余壶数。
- 5 层低难度防御（800 / 1,200 / 1,800 / 2,700 / 4,050）+ 之后无尽 ×1.5。
- 3 心、失败重试、最高层数本地保存。
- 不做排行榜、广告、内购、皮肤。

## 8. 风险

| 风险 | 对策 |
|---|---|
| 球太多看不懂 | 初始 1 颗，逐层最多 4 颗，每颗一句特性 |
| 三选一选择困难 | 3 个选项，明确“新球/强化/回心” |
| 随机布局太难 | 第 1 排固定成长门；前 3 层低防御 |
| 数值崩 | 先固定 5 层，记录每层通过率再调 |
| 球之间差异不明显 | 巨力/旋弧/分裂必须有肉眼可见差异 |
| 破坏爽快模式 | 所有爬塔逻辑走 `mode === 'tower'` 分支；基线可回退 |

## 9. 实施顺序

1. 控制层：按住蓄力、右上角重开、旋弧/收尾。
2. 爬塔：层数/防御/伤害、达标立即过关。
3. 冰球：初始 1 颗、三选一、底部选球条。
4. 随机布局：门类型/位置/宽度 + 钉子抖动。
5. 失败/重试/最高层。
6. 测试 + 文档 + 单文件构建。
7. 提交到 `feature/tower-mode`，`master` 保持 v0.3。

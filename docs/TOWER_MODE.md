# 爬塔模式 · 调研与设计（冰球版）

> 分支：`feature/tower-mode`
> 基线：`master` / `v0.3-baseline`，随时可回退（见 `ROLLBACK.md`）
> 本版已把“石头合并”改成“不同冰球 + 单球强化”，参考《哥布林弹球 Peglin》。

## 1. 参考玩法

| 游戏/类型 | 核心机制 | 可借鉴点 |
|---|---|---|
| **哥布林弹球 Peglin** | 收集不同弹珠，每颗弹珠有独特效果；弹珠撞钉子造成伤害；关卡间强化弹珠/拿遗物 | **不同球 = 不同 build**；单球强化；每发选择用哪颗球 |
| **魔塔 / Magic Tower** | 攻击 > 防御才能击杀 | 层数门槛清晰 |
| **Random Dice: Defense** | 合并骰子提升攻击，抵御波次 | 短波次、成长可见 |
| **Merge Defense 系列** | 合并单位/炮塔，守住波次 | 合并/强化后战力立刻变化 |
| **《赵云与阿斗》** | 合并 + 塔防，抖音畅销 | 合并+塔防在抖音可行 |
| **《矮人爬爬塔》** | 点击/合并军队，向上爬塔 | 爬塔目标感 |

### 调研结论

1. **Peglin 的核心不是“合并”，而是“每颗球不一样”**：球的特性决定这一发怎么打。
2. **强化要落到具体球上**：玩家要能说“我这颗旋弧球升到 3 级了”，而不是“我有一堆石头”。
3. **层数门槛要清晰**：伤害 / 防御一眼可见。
4. **短局 + 快速重试**：3 心，失败保留 build。
5. **不要同时做两套复杂操作**：冰壶投掷是操作核心，爬塔只做“选球/强化”决策。

## 2. 核心循环

```
选择爬塔（初始只有 1 颗标准球）
  → 第 N 层：怪物防御 DEF，门/钉子随机布局
  → 每层可投掷数 = 拥有的球数；每颗球本层只能用一次
  → 伤害 = 本层得分 × 该冰球攻击倍率
  → 伤害 ≥ DEF？立即突破，不再等剩余球数
      是：三选一（新冰球 / 强化现有冰球）→ 下一层
      否：球用光仍不足 → 失去 1 心 → 重试本层（保留冰球）
  → 3 心用完，本次爬塔结束
```

**和闯关模式的关系：**

- 闯关模式：10 关独立手工关卡；每关预设冰球，没有三选一/跨关继承。
- 爬塔模式：随机门序、无限层，逐层打防御，三选一收集/强化冰球。
- 共用物理、门、钉子、计分、冰球；区别在关卡布局、目标与成长规则。

## 3. 冰球

### 3.1 八种冰球（MVP）

| 冰球 | 半径 | 初始攻击 | 特性 |
|---|---|---|---|
| **标准球** | 1.0×R0 | +0% | 初始球，均衡稳定 |
| **巨力球** | 1.3×R0 | +5% | 更大更重，撞击更强 |
| **旋弧球** | 0.95×R0 | +10% | 旋弧 ×1.6，适合绕门 |
| **分裂球** | 0.9×R0 | +15% | 首次穿过门时分裂成两颗 |
| **磁力球** | 1.0×R0 | +8% | 投出后吸附附近钉子 4 秒 |
| **穿透球** | 0.95×R0 | +12% | 穿透前 3 个钉子，不减速 |
| **弹跳球** | 1.0×R0 | +6% | 撞墙反弹更强，适合贴边 |
| **爆裂球** | 1.0×R0 | +14% | 首次撞钉引发爆炸，清一小片 |

> R0 = 0.16m。每升 1 级，半径 +5%，攻击 +18%。
> 初始只有标准球；其余通过层间三选一获得。

### 3.2 层间三选一

- 每层突破后，从 **3 个完全随机选项**里选 1 个：
  - **新增冰球**：随机一种球，数量 +1；如果该种类已有，新球直接使用该种类当前等级。
  - **强化现有冰球**：随机一种已有球，**该种类等级 +1**（最高 Lv.5）。同类所有球共享等级。
- 选项池 = 所有球种类（8 种）+ 所有可升级种类；洗牌取 3。
- 只有选完才能进入下一层。
- 没有石头、没有合并；球种类等级 + 数量就是 build。
- 目标：让玩家形成“多球轮换 vs 单球极限强化”的 build 选择。

### 3.3 选球条

- 底部**每种球只有一个按钮**，不会因为同种球有 2 颗就出现 2 个框。
- 按钮显示：`名称 ×剩余数量` + `Lv.等级`。
- 数量 > 4 种时横向滑动；同种 2 颗显示 `×2`。
- 仅在瞄准阶段可切换；本层剩余 0 的球变灰。
- 切换后，瞄准中的冰球半径、颜色、旋弧倍率立即变化。
- 获得/强化后自动选中该种类。

### 3.4 每球每层一次

- 每颗球实例每层只能投一次；同种有 2 颗就可以投 2 次。
- 球条显示“剩余数量”，投一次减 1；减到 0 变灰。
- 本层投掷数 = 所有球数量之和。
- 初始 1 颗球 → 第 1 层只有 1 次投掷；不够就失败。
- 选择“新增球”增加数量；选择“强化”提高该种类等级。
- 重试本层会重置所有球的“本层已用”数量。

## 4. 层数数值

| 层 | 怪物防御 | 玩家目标 |
|---|---|---|
| 1 | 300 | 极低难度；1 颗标准球，1 壶通常可过 |
| 2 | 450 | 拿到第 2 颗球或强化后 |
| 3 | 675 | 需要选对球/门链 |
| 4 | 1,012 | 需要 2~3 次补给 |
| 5 | 1,519 | 第一次小考 |
| 6+ | ×1.5 / 层 | 无尽爬塔 |

> 前 3 层尽量低难度，先让玩家体验“选球/强化”的成长，再逐步加门槛。

## 5. 失败与重试

- 每层 3 心。
- 伤害 < DEF：失去 1 心，**保留所有冰球等级**，重试本层。
- 0 心：本次爬塔结束，显示到达层数 + 最高层数。
- 暂不做广告复活；后续可加。

## 6. UI

### 6.1 模式选择

```
[ 闯关模式 ]   10 关手工布局 + 三选一 build
[ 爬塔模式 ]   选球 + 强化，逐层打防御
```

### 6.2 爬塔 HUD

- 第 N 层
- 怪物防御 DEF（大本营上方也有 DEF 徽章）
- 伤害进度条：`当前伤害 / DEF`
- 达标立即过关，不再等剩余壶数
- 心数 `❤❤❤`
- 当前冰球攻击加成

### 6.3 底部选球条

```
[标准 ×2 Lv.1] [旋弧 ×1 Lv.2] [分裂 ×1 Lv.1]
```

- **每种球只有一个按钮**，同种多颗只显示 `×数量`。
- 选中球有高亮边框（颜色对应球色）。
- 本层剩余 0 的球变灰；滑行时按钮禁用。
- 种类超过 4 个时横向滑动。

### 6.4 层间界面

```
第 N 层突破！

伤害 956 / DEF 300

[标准球 Lv.1 → Lv.2]   [旋弧球 · 新冰球]
[分裂球 · 新冰球]

选择 1 个：新冰球 / 强化现有冰球
（选完才能进入下一层）

[ 进入第 N+1 层 ]
```

### 6.5 每层随机布局

- 每层重新生成 **3~4 排门**：排距、类型、位置、宽度随机；部分门会左右移动。
- 第 1 排固定为两个成长门（变大/分裂），保证前期能吃到。
- 第 2/3 排每排 1~3 个门，随层数增加减益概率、缩小门宽。
- 门画成**完整圆形触发区**：直径 = 设计宽度；圆内任何位置都能触发，金色内圆是 PERFECT 判定范围。
- 第 1 排下移到 11.4m 之后，避免冰球出生点落在圆内。
- 30 个钉子也做随机抖动/整体偏移，避免每层完全一样。
- 门可以重叠；如果同一位置同时吃到多个门，**所有 buff 全部生效**。
- 分裂门放在最后结算，让子球继承前面的变大/加速/倍率。
- 重试本层时保持同一布局，避免“换图刷分”。

## 7. MVP 范围

- 爬塔模式独立入口；闯关模式复用同一套冰球/三选一系统，但使用手工关卡。
- 初始 1 颗标准球，最多 8 种球类型；同种可重复获得，球数量可超过 4。
- 每层三选一：新冰球 / 强化现有球（完全随机）。
- 每层随机门+钉子布局，重试保持布局。
- 伤害达标立即过关，不等待剩余壶数。
- 5 层低难度防御（300 / 450 / 675 / 1,012 / 1,519）+ 之后无尽 ×1.5。
- 3 心、失败重试、最高层数本地保存。
- 不做排行榜、广告、内购、皮肤。

## 8. 风险

| 风险 | 对策 |
|---|---|
| 球太多看不懂 | 初始 1 颗，逐层增加；同种球可重复，最多 8 种特性 |
| 三选一选择困难 | 3 个选项，明确“新球/强化现有球” |
| 随机布局太难 | 第 1 排固定成长门；前 3 层低防御 |
| 数值崩 | 先固定 5 层，记录每层通过率再调 |
| 球之间差异不明显 | 巨力/旋弧/分裂必须有肉眼可见差异 |
| 破坏闯关模式 | 爬塔逻辑与闯关逻辑分离；闯关使用 `mode === 'campaign'` 和固定关卡表 |

## 9. 实施顺序

1. 控制层：按住瞄准/松手满力、右上角重开、旋弧/收尾。
2. 爬塔：层数/防御/伤害、达标立即过关。
3. 冰球：初始 1 颗、三选一、底部选球条。
4. 随机布局：门类型/位置/宽度 + 钉子抖动。
5. 失败/重试/最高层。
6. 测试 + 文档 + 单文件构建。
7. 提交到 `feature/tower-mode`，`master` 保持 v0.3。

# 试玩与测试报告

- 日期：2026-10-28
- 版本：v0.6（爽快模式 + 冰球爬塔）
- 运行方式：`play.cmd` / `dist/curling-gates.html`
- 测试环境：Windows + 系统 Chrome + Playwright 1.64
- 视口：390 × 844（竖屏），DPR 2

## 1. 本版针对反馈的改动

| 反馈 | 改动 |
|---|---|
| 手机下滑容易划出屏幕，难满力 | 按住蓄力（约 1.05s 到顶后回落），左右拖动瞄准，松手投掷 |
| 第一球没发挥好想重开 | 右上角 **↻ 重开**，瞄准/滑行中随时立即重置本局 |
| 旋转选择不想每次重选 | 左/中/右旋转**记忆**，新球、重开、刷新后保持 |
| 左右旋弧度小 | 旋弧 `0.14 → 0.26`，低速保留 60% 旋力 |
| 发球后球速快、每球收尾慢 | 滑行 `×1.55 → ×1.15`；低速摩擦增强 + 停止阈值 0.15；球间等待 1s + 点击跳过 |
| 初始球太多 | 初始只有 **1 颗标准球**；层间三选一（新球 / 强化现有球），新球可重复种类 |
| 必须用光 3 壶才过关 | **伤害达标立即过关**，不等剩余球数 |
| 每层布局都一样 | 每层随机生成门的类型/位置/宽度/排距，部分门会左右移动；钉子随机抖动；重试保持同布局 |
| 每颗球每层只能用一次 | 投出后变灰，不能重复使用；本层投掷数 = 拥有球数 |
| 力度条太丑 | 改为球旁**平滑渐变胶囊**：蓝→绿→红、刻度线、白色圆点、满力红色 MAX；到顶往返 |

## 3. 实测数据

### 爬塔模式

```
初始：1 颗标准球 Lv.1；第 1 层 DEF 300
第 1 壶：伤害 846 / 300 → 立即过关（不再投剩余球）
三选一：标准球 Lv.2 / 旋弧球新球 / 分裂球新球（完全随机）
选择：旋弧球 · 新冰球 → 底部变 2 颗球
第 2 层：DEF 450；门/钉子随机布局，部分门移动
2 颗球各投一次：伤害 0 → 掉 1 心（剩 2），可重试
```

### 爽快模式

```
3 壶总分：3,281
星级：★☆☆
命中钉子：22 / 90
```

> 每壶分数会随随机门位略有浮动。

### 手感测量

```
滑行到 between：约 4.75s（含 0.3s 停稳等待）
低速收尾：1.5 m/s → 停稳约 0.5s
满旋横向：最大约 2.24m
```

## 5. 已知限制

- 无头浏览器需要 `--disable-frame-rate-limit` 等参数才能稳定跑 RAF；真实浏览器不受影响。
- 爬塔随机布局目前是“门类型/位置/宽度 + 钉子抖动”，还没有新机关/新怪物。
- 冰球之间差异还需要更强的特效/音效强化。
- 爬塔数值只验证到第 2 层，后续层数需要真实通过率再调。
- 美术为程序化占位；音效为 WebAudio 合成。
- 震动依赖 `navigator.vibrate`，iOS Safari 不支持；抖音内需换 `tt.vibrateShort`。
- 未接抖音 SDK、排行榜、广告、录屏；分享为浏览器 `navigator.share` / 剪贴板。
- 未做 Cocos 构建；Cocos spike 需要本机安装 Cocos Creator 3.8.7+。

## 6. 试玩建议

1. 爽快模式：按住蓄力、左右瞄准、松手；观察力度条到顶回落。
2. 右上角重开，确认旋转保持。
3. 爬塔模式：第 1 层通常 1 壶就过；三选一拿新球/强化。
4. 第 2 层看门布局是否变化；切底部冰球看半径/颜色。
5. 故意弱投 3 壶，确认掉心/重试/继承。
6. 结算页试一下分享成绩。

如果爬塔不够有感觉，下一步优先：
- 三选一动画 + 攻击数字跳动
- 冰球特效差异（巨力/旋弧/分裂）
- 第 1~5 层通过率实测

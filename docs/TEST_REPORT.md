# 试玩与测试报告

- 日期：2026-10-28
- 版本：v0.5（爽快模式 + 冰球爬塔模式）
- 运行方式：`play.cmd` / `dist/curling-gates.html`
- 测试环境：Windows + 系统 Chrome + Playwright 1.64
- 视口：390 × 844（竖屏），DPR 2

## 1. 本版针对反馈的改动

| 反馈 | 改动 |
|---|---|
| 手机下滑容易划出屏幕，难满力 | 改为**按住蓄力**（约 1.05s 满力），左右拖动瞄准，松手投掷 |
| 第一球没发挥好想重开 | 右上角 **↻ 重开**，瞄准/滑行中随时立即重置本局 |
| 旋转选择不想每次重选 | 左/中/右旋转**记忆**，新球、重开、刷新后保持 |
| 左右旋弧度小 | 旋弧 `0.14 → 0.26`，低速保留 60% 旋力 |
| 发球后球速快、每球收尾慢 | 滑行 `×1.55 → ×1.15`；低速摩擦增强 + 停止阈值 0.15；球间等待 1s + 点击跳过 |
| 想要关卡继承/成长 | 新增**爬塔模式**：层数/防御、石头合并、3 选 1 强化、3 心 |

## 5. 已知限制

- 无头浏览器需要 `--disable-frame-rate-limit` 等参数才能稳定跑 RAF；真实浏览器不受影响。
- 爬塔模式 MVP 复用同一套门/钉子布局，层间变化主要来自数值和 build。
- 石头合并/强化界面是首版，操作和动画还可以更顺。
- 爬塔数值只验证到第 2 层，后续层数需要真实通过率再调。
- 美术为程序化占位；音效为 WebAudio 合成。
- 震动依赖 `navigator.vibrate`，iOS Safari 不支持；抖音内需换 `tt.vibrateShort`。
- 未接抖音 SDK、排行榜、广告、录屏。
- 未做 Cocos 构建；Cocos spike 需要本机安装 Cocos Creator 3.8.7+。

## 6. 试玩建议

1. 先玩爽快模式：按住蓄力、左右瞄准、松手投掷。
2. 试一次右上角重开，确认旋转不被重置。
3. 玩爬塔模式：第 1 层突破后，合并两颗 L1，选一个强化，再进第 2 层。
4. 第 2 层故意弱投，确认掉心/重试/继承。
5. 回主页，确认爽快模式仍然正常。

如果爬塔的“合并/强化”不够有感觉，优先加：
- 合并动画 + 攻击数字跳动
- 强化选项更差异化（门强化/额外石头）
- 第 1~5 层的通过率实测

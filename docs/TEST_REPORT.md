# 试玩与测试报告

- 日期：2026-10-29
- 版本：v0.8（10 关闯关 + 冰球爬塔）
- 运行方式：`play.cmd` / `dist/curling-gates.html`
- 测试环境：Windows + 系统 Chrome + Playwright 1.64
- 视口：390 × 844（竖屏），DPR 2

## 1. 本版针对反馈的改动

| 反馈 | 改动 |
|---|---|
| 爽快模式改闯关模式 | 10 个**独立**手工关卡；选关逐关解锁；每关独立预设冰球，无三选一/升级/跨关继承 |
| 取消力度和擦冰，始终满力 | 删除蓄力/力度条/擦冰体力；按住只瞄准，松手立即以旧版满力 **11.5 m/s** 投掷 |
| 左右旋弧度再大点 | 旋弧加速度 `0.26 → 0.90`；满旋横向约 2.0m，接近边线 |
| 圆形 buff 区，不要不可触发区 | 门改为**直径 = 设计宽度的完整圆**；圆内全部可触发；金色内圆 = PERFECT；删除横向条带 |
| 第一排圆不能盖住出生点 | 第 1 排下移到 11.4~13.6m，投掷前所有门 `used=false` |
| 瞄准方向与路线不一致 | 角度改为“反投影手指世界坐标”，瞄准线直接画预测轨迹；直线/斜线都会从冰球经过手指，旋转时显示真实弧线 |
| 爬塔初始球太多 | 爬塔初始只有 **1 颗标准球**；层间三选一（新球 / 强化现有球） |
| 必须用光 3 壶才过关 | **伤害达标立即过关**，不等剩余球数 |
| 每层布局都一样 | 每层随机生成门的类型/位置/宽度/排距，部分门会左右移动；钉子随机抖动；重试保持同布局 |
| 每颗球每层只能用一次 | 球条每种球一个按钮，显示 `×剩余`；投一次减 1，减到 0 变灰 |

## 3. 实测数据

### 闯关模式

```
第 1 关 初试冰面：380 / 300 伤害 → 过
第 2 关 分裂之门：757 / 500 → 过
第 3 关 精准穿门：钉子 11 / 10 → 过
第 4 关 双线抉择：1212 / 700 → 过
第 5 关 重叠增益：门 8 / 6 → 过
第 6 关 钉子风暴：钉子 32 / 26 → 过
第 7 关 风险之门：2547 / 2300 → 过
第 8 关 磁力迷宫：门 9 / 8 → 过
第 9 关 极限冰面：5334 / 3500 → 过
第 10 关 冰面首领：12911 / 12500 → 通关
```

- 选关：初始仅第 1 关解锁；通关解锁下一关
- 每关独立配球：没有三选一/升级/跨关继承
- 失败：球用光未达标 → 重试本关或返回选关
- 第 10 关达标后显示「闯关成功！」

### 爬塔模式

```
初始：1 颗标准球 Lv.1；第 1 层 DEF 300
投掷前：第一排两个圆门 used=false（出生点不在圈内）
第 1 壶：伤害约 600 / 300 → 立即过关（不再投剩余球）
圆形门测试：两个同心圆同时触发，used=[true,true]，gateMult=1，半径 0.16→0.232
圆外测试：偏离半径的门保持 used=false
三选一：3 个完全随机选项（新增球 / 强化某种类）
第 2 层：DEF 450；门/钉子随机布局，部分门移动
弱投用光球：伤害不足 → 掉 1 心（剩 2），可重试
```

### 控制与瞄准

```
初速：固定 11.5 m/s
满旋横向：约 2.0m
圆形门：直径 = 设计宽度；圆外不触发
按住只瞄准，松手立即投掷
```

> 瞄准轨迹按实际物理投影；旋转时线会弯。

### 手感测量

```
单壶滑行到 between：约 4.5~5s（含 0.3s 停稳等待）
低速收尾：1.5 m/s → 停稳约 0.5s
满旋横向：最大约 2.0m（接近边线）
初速：固定 11.5 m/s（旧版满力）
```

## 5. 已知限制

- 无头浏览器需要 `--disable-frame-rate-limit` 等参数才能稳定跑 RAF；真实浏览器不受影响。
- 爬塔随机布局目前是“门类型/位置/宽度 + 钉子抖动”，还没有新机关/新怪物。
- 冰球之间差异还需要更强的特效/音效强化。
- 爬塔数值只验证到第 2 层，后续层数需要真实通过率再调。
- 美术为程序化占位；音效为 WebAudio 合成。
- 震动依赖 `navigator.vibrate`，iOS Safari 不支持；抖音内需换 `tt.vibrateShort`。
- 未接抖音 SDK、排行榜、广告、录屏；分享为浏览器 `navigator.share` / 剪贴板。
- 未做 Cocos 构建；Cocos spike 需要本机安装 Cocos Creator 3.8.7+。

## 6. 试玩建议

1. 闯关模式：按住瞄准，松手；第 1 关目标 300，先熟悉满力与圆形门。
2. 第 2 关用预设的标准 + 分裂，感受分裂球；关卡间不继承配置。
3. 第 3 关开始目标变成钉子；第 5 关尝试一次吃两个重叠门。
4. 第 7/9 关注意侧边缩小/粘滞，别只看高收益颜色。
5. 第 10 关首领：本关预设 10 颗球，合理分配直投和旋弧。
6. 结算页试一下分享成绩。

如果爬塔不够有感觉，下一步优先：
- 三选一动画 + 攻击数字跳动
- 冰球特效差异（巨力/旋弧/分裂）
- 第 1~5 层通过率实测

# 试玩与测试报告

- 日期：2026-10-28
- 版本：v0.3
- 运行方式：`play.cmd`（本地服务器）/ `dist/curling-gates.html`（单文件）

## 1. 本版针对反馈的改动

| 反馈 | 改动 |
|---|---|
| 冰壶滑动稍慢 | 滑行时间 ×1.55；高速细分步进防穿透；加入速度线 |

## 5. 发现与修复

| 问题 | 处理 |
|---|---|
| 首壶只命中 1 个钉子，不够爽 | 钉子增至 30 个 + 两代连锁；首壶最高 29/30 |
| 第一排门中间有缝，直线投掷会 MISS | 第一排改为两块宽门，直线必吃一个 |
| 结算每壶分数只统计大本营分 | 记录 `throwStartScore`，改为整壶得分 |
| 结算看不到倍率峰值 | 增加“最高倍率”“最高连击”“最高门链” |
| 轨迹只显示 58%，玩家不知道壶会停哪 | 显示完整轨迹，后半段淡出，ghost 在真实停点 |
| 钉子/门每帧 radial gradient + shadowBlur 较重 | 改为扁平填充 + 多层描边；移除门 shadowBlur |
| `MISS` 飘字过大、遮挡门 | 缩小并上移 |
| 结算页仍显示“如何玩” | 结算态隐藏 |
| 投掷等待感强 | 滑行 ×1.55 + 速度线 + 命中停顿 |
| 缺少策略 | 门链 + MISS 断链 + 目标分/星级 |
| 结算没有目标感 | 星级 + “距离目标还差 X 分” |

## 6. 已知限制

- 无头浏览器需要 `--disable-frame-rate-limit` 等参数才能稳定跑 RAF；真实浏览器不受影响。
- 美术为程序化占位，不是最终风格。
- 音效为 WebAudio 合成，未做真机音量/延迟测试。
- 震动依赖 `navigator.vibrate`；iOS Safari 不支持，抖音内需换 `tt.vibrateShort`。
- 未接抖音 SDK、排行榜、广告、录屏。
- 未做 Cocos 构建；Cocos spike 需要本机安装 Cocos Creator 3.8.7+。

## 7. 试玩验收建议

请按以下顺序试玩 10 局：

1. 先直线投，感受“变大 + 连锁清屏”。
2. 再尝试左右门 + 旋转，感受“瞄准打门”。
3. 试着连续命中 3 排门，观察门链倍率。
4. 试一次满力 / 半力，感受力度曲线。
5. 试一次擦冰救壶。
6. 看结算的星级和“差 X 分”，判断是否想再来一局。

如果 10 局后仍不想再来，优先继续调“爽感”，不要加内容。

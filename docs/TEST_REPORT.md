# 试玩与测试报告

- 日期：2026-10-28
- 版本：v0.7（爽快模式 + 冰球爬塔）
- 运行方式：`play.cmd` / `dist/curling-gates.html`
- 测试环境：Windows + 系统 Chrome + Playwright 1.64
- 视口：390 × 844（竖屏），DPR 2

## 1. 本版针对反馈的改动

| 反馈 | 改动 |
|---|---|
| 取消力度和擦冰，始终满力 | 删除蓄力/力度条/擦冰体力；按住只瞄准，松手立即以固定 **9.2 m/s** 满力投掷 |
| 左右旋弧度再大点 | 旋弧加速度 `0.26 → 0.90`；满旋横向约 2.1~2.2m，接近边线 |
| 圆形 buff 区，不要不可触发区 | 门改为**直径 = 设计宽度的完整圆**；圆内全部可触发；金色内圆 = PERFECT；删除横向条带 |
| 第一排圆不能盖住出生点 | 第 1 排下移到 11.4~13.6m，投掷前所有门 `used=false` |
| 瞄准线 | 从冰壶到手指画一条延长线，**指哪瞄哪**；按住时移动手指调整 |
| 初始球太多 | 初始只有 **1 颗标准球**；层间三选一（新球 / 强化现有球），新球可重复种类 |
| 必须用光 3 壶才过关 | **伤害达标立即过关**，不等剩余球数 |
| 每层布局都一样 | 每层随机生成门的类型/位置/宽度/排距，部分门会左右移动；钉子随机抖动；重试保持同布局 |
| 每颗球每层只能用一次 | 球条每种球一个按钮，显示 `×剩余`；投一次减 1，减到 0 变灰 |

## 3. 实测数据

### 爬塔模式

```
初始：1 颗标准球 Lv.1；第 1 层 DEF 300
投掷前：第一排两个圆门 used=false（出生点不在圈内）
第 1 壶：伤害 962 / 300 → 立即过关（不再投剩余球）
圆形门测试：两个同心圆同时触发，used=[true,true]，gateMult=1，半径 0.16→0.232
圆外测试：偏离半径的门保持 used=false
三选一：3 个完全随机选项（新增球 / 强化某种类）
第 2 层：DEF 450；门/钉子随机布局，部分门移动
弱投用光球：伤害不足 → 掉 1 心（剩 2），可重试
```

### 爽快模式

```
3 壶总分：约 3,000~4,000（随圆形门位浮动）
星级：★☆☆
命中钉子：22 / 90
```

> 每壶分数会随随机门位略有浮动。

### 手感测量

```
单壶滑行到 between：约 4.5~5s（含 0.3s 停稳等待）
低速收尾：1.5 m/s → 停稳约 0.5s
满旋横向：最大约 2.19m（接近边线）
初速：固定 9.2 m/s
```

## 5. 已知限制

- 无头浏览器需要 `--disable-frame-rate-limit` 等参数才能稳定跑 RAF；真实浏览器不受影响。
- 爬塔随机布局目前是“门类型/位置/宽度 + 钉子抖动”，还没有新机关/新怪物。
- 冰球之间差异还需要更强的特效/音效强化。
- 爬塔数值只验证到第 2 层，后续层数需要真实通过率再调。
- 美术为程序化占位；音效为 WebAudio 合成。
- 震动依赖 `navigator.vibrate`，iOS Safari 不支持；抖音内需换 `tt.vibrateShort`。
- 未接抖音 SDK、排行榜、广告、录屏；分享为浏览器 `navigator.share` / 剪贴板。
- 未做 Cocos 构建；Cocos spike 需要本机安装 Cocos Creator 3.8.7+。

## 6. 试玩建议

1. 爽快模式：按住瞄准，手指指向目标，松手；所有球都是满力，观察弧线和圆形门。
2. 右上角重开，确认旋转保持。
3. 爬塔模式：第 1 层通常 1 壶就过；三选一拿新球/强化。
4. 第 2 层看门布局是否变化；切底部冰球看半径/颜色。
5. 故意瞄空/用光球，确认掉心/重试/继承。
6. 结算页试一下分享成绩。

如果爬塔不够有感觉，下一步优先：
- 三选一动画 + 攻击数字跳动
- 冰球特效差异（巨力/旋弧/分裂）
- 第 1~5 层通过率实测

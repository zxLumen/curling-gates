# 抖音小游戏命名规范与候选名

> 来源：抖音开放平台创建小游戏时的「更多说明」。
> 当前「冰壶大作战」只是**工作名**，不是最终名称。

## 1. 平台规则（摘录）

- 正式上架前，名称可保留 **30 天**；未及时发布版本，名称会被释放，其他用户可抢占。
- 正式上架后，每个自然年可修改 **2 次**。
- 名称仅支持**中文、数字、英文**；不能用特殊符号、繁体字、生僻字、拆字或颜文字。
- 名称不可使用**单个普通名词**（如“摩托”“恐龙”）。
- 名称不可使用**通用游戏种类名**（如“斗地主”“麻将”）。
- 名称的信息表达必须和小游戏内容**一致**。
- 名称不得混有商业化用语、热门应用名称，不得侵犯他人知识产权（如“今日头条”“抖音”等）。
- 名称审核约 **1~2 个工作日**。

## 2. 当前工作名评估

**《冰壶大作战》**

| 维度 | 评估 |
|---|---|
| 字符合规 | ✅ 中文，无特殊符号 |
| 内容一致 | ✅ 冰壶 + 闯关对战 |
| 单个普通名词 | ⚠️ 不是单个名词，但“大作战”是常见游戏后缀，辨识度一般 |
| 通用游戏种类 | ⚠️ 不属于“斗地主/麻将”这类品类名，但偏描述性 |
| 重名/侵权风险 | ⚠️ 公开搜索能看到同名桌游/小游戏内容，需查重 |
| 建议 | **仅作工作名**，上线前换更有辨识度的名字 |

## 3. 候选名

| 候选 | 记忆点 | 与玩法一致性 | 风险 |
|---|---|---|---|
| **一壶定胜负** | 强，口语化 | 3 壶定胜负 | 可能被其他棋牌/体育游戏使用，需查重 |
| **巨壶大冲撞** | 强，画面感 | 变大 + 撞击清屏 | “巨”字较夸张，需确认不误导 |
| **冰壶变变变** | 中，玩法直给 | 增益门改变冰壶 | 偏儿童向，需看目标用户 |
| **冰壶超进化** | 中，成长感 | 变大/分裂/加速 | “进化”较常见 |
| **爆分冰壶** | 强，爽感 | 连击爆分 | 偏直白，可能显商业化 |
| **冰壶开道** | 中，动作感 | 冲过门阵 | 略抽象 |
| **冰壶清屏王** | 强，爽感 | 清屏 | “王”字常见，查重 |
| **冰上弹珠** | 强，类比清晰 | 门阵 + 撞击 | 可能被弹珠类游戏占用 |

### 推荐短名单

1. **一壶定胜负**（最稳，内容一致，口语传播好）
2. **巨壶大冲撞**（最贴“变大 + 清屏”的爽点）
3. **冰壶变变变**（最贴“增益门”玩法）

## 4. 上线前查重清单

- [ ] 抖音 App 搜索候选名，看是否有同名小游戏/账号/话题
- [ ] 抖音小游戏中心搜索候选名
- [ ] 微信小游戏搜索候选名
- [ ] 应用商店（TapTap/好游快爆/应用宝）搜索
- [ ] 中国商标网查询同名/近似商标（第 9、41 类重点）
- [ ] 中国版权保护中心查软著重名
- [ ] 搜索引擎查“候选名 + 游戏/商标/公司”
- [ ] 确认名称与软著名称、主体信息三者可对齐

## 5. 时间安排

- 名称审核 1~2 个工作日。
- 名称保留 30 天：**不要过早锁定**，等包体接近可提审时再定名。
- 上架后每年只能改 2 次：第一版名字要一次到位。
- 软著/备案名称建议与最终游戏名一致，避免后续变更。

## 6. 命名红线

- 不使用“冬奥”“国家队”“冰墩墩”等官方/IP 标识
- 不使用“抖音”“今日头条”“字节”等平台名
- 不使用“最强”“第一”“国家级”等绝对化/商业化用语
- 不使用繁体、生僻字、拆字、颜文字、特殊符号
- 不使用纯品类名（“冰壶”“冰壶游戏”单独作为名称风险高）

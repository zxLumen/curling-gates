# 冰壶大作战 · 游戏设计（V2）

> 版本：0.4（增益门 + 门链 + 目标星级 + 爬塔模式）
> 核心：**用冰壶的瞄准，打中想增益门，把壶变大/分裂/加速，最后一波清屏爆分。**

## 1. 一句话定位

冰壶题材的「瞄准打门 + 滚雪球清屏」爽游。

- 不是冰壶模拟器
- 不是纯数值门游戏
- 是「冰壶的投掷手感 + 肉鸽式的门选择 + 保龄球式的清屏反馈」

## 2. 三层核心玩点

| 层 | 玩家在做什么 | 爽点 |
|---|---|---|
| 瞄准层 | 按住蓄力、左右拖动瞄准、松手投掷，让壶穿过想吃的门 | “我瞄得真准” |
| Build 层 | 在岔路选择变大、分裂、加速、倍率，或冒险吃风险门 | “这局 build 成了” |
| Payoff 层 | 变大/分裂后的壶撞飞钉子，连击爆分 | “太解压了” |

**关键差异：门是“用壶打中的”，不是“点左/点右选的”。**

- 每排 2~3 个门，宽窄、位置不同
- 窄门高收益，宽门低收益
- 打偏 = 没吃到，或吃到旁边的 debuff
- 门中心有完美判定，额外加成

## 3. 核心循环

```
选关/开局
  → 观察门与钉子布局
  → 按住蓄力（约 1.05 秒到满）
  → 左右拖动瞄准
  → 松手投掷
  → 穿过门：变大 / 分裂 / 加速 / 磁铁 / 穿透
  → 滑行中擦冰微调
  → 撞飞钉子、连击、爆分
  → 结算 / 下一壶 / 再来一局
```

一局 3 壶，约 1~2 分钟。

## 4. 门系统

### 4.1 分类

| 类型 | 颜色 | 示例 | 作用 |
|---|---|---|---|
| 成长 | 绿 | 变大、分裂、克隆 | 滚雪球 |
| 运动 | 蓝 | 加速、弹力、磁铁、穿透 | 改变轨迹/撞击 |
| 收益 | 金 | 倍率、金币、连击延长 | 放大分数 |
| 风险 | 紫 | 变小但倍率 +、加速但难控 | 高风险高回报 |
| 减益 | 红 | 变小、减速、粘滞、反向、传送 | 惩罚失误 |
| 功能 | 白 | 护盾、净化、重随 | 容错 |

### 4.2 首版门

| 门 | 效果 | 数值 |
|---|---|---|
| 变大 | 半径 +45% | 上限 3 倍 |
| 分裂 | 一分为二 | 子壶半径 ×0.72，上限 12 个 |
| 加速 | 速度 +30% | 上限 13 m/s |
| 倍率 | 分数倍率 +1x | 上限 +5x |
| 磁铁 | 吸附附近钉子 | 半径 2.6m，持续 4s |
| 穿透 | 穿过前 3 个钉子 | 不减速 |
| 变小 | 半径 -28%，倍率 +1x | 风险门 |
| 粘滞 | 摩擦 +45% | 减益门 |

### 4.3 摆放规则

1. 每排至少一个成长门
2. 减益门不能是唯一通路
3. 窄门高收益，宽门低收益
4. 连续两排不出现同类型大 buff
5. 连续 2 次没吃到成长门，下一排保底
6. 图标 + 颜色 + 数字，一眼看懂

## 5. 物理与手感

| 项 | 设计 |
|---|---|
| 模拟 | 固定 60Hz，确定性 |
| 壶半径 | 0.16m（视觉可放大） |
| 赛道 | 4.75 × 36m |
| 初速 | 4.5 ~ 11.5 m/s |
| 摩擦 | 1.55 m/s²；速度 <1.6m/s 时平滑增至 2.4 倍（收尾更快） |
| 弧线 | `0.26 m/s² × (0.6 + 0.4 × 速度/8)`，低速保留 60% 旋力 |
| 擦冰 | 摩擦 ×0.75，弧线 ×0.7，体力 2.2s |
| 碰撞 | 壶-壶弹性 0.9；壶-钉轻质弹飞 |
| 钉子连锁 | 命中后以 0.66m 半径触发两代连锁，最多覆盖 30 钉菱形阵 |
| **滑行速度** | 物理时间 ×1.15；高速时细分步进防穿透 |
| 停止阈值 | 0.15 m/s |

**手感目标：**

- 全力投掷滑行 4~5 秒，最后 0.5 秒内停稳
- 满旋横向偏移 2.2~2.8m
- 大壶撞钉子：钉子飞、壶几乎不减速
- 小壶撞钉子：壶明显减速

## 6. 计分

```
单钉 = 15 分 × 总倍率
大本营 = 中心 250 / 中环 120 / 外环 60
连击 = 每命中 +0.1x，1.6s 不命中则清零（上限 6x）
门链 = 连续命中门，每多一层 +0.5x（上限 +2x），MISS 断链
总倍率 = 1 + 门倍率 + 连击倍率 + 门链倍率，上限 20x
清屏奖励 = 800 × 本壶峰值倍率
```

**目标与星级：**

| 星级 | 分数 |
|---|---|
| 1 星 | 3,000 |
| 2 星 | 6,000 |
| 3 星 | 10,000 |

一局 3 壶累计总分，结算显示星级、最高分、最高倍率、最高连击、最高门链、每壶得分，以及“距离目标还差 X 分”。

## 6.5 策略层

这个玩法的策略不是“撞得越多越好”，而是 **门链 × 倍率 × 停球位置**：

| 选择 | 收益 | 代价 |
|---|---|---|
| 大力投掷 | 穿过钉子区、清屏、连击高 | 容易冲过大本营，丢掉停球分 |
| 小力投掷 | 停在圆心附近，拿 250 分基础分 | 钉子撞得少，连击低 |
| 走成长门 | 变大/分裂，后续撞击更强 | 可能错过倍率/磁铁门 |
| 走收益门 | 倍率 +1x，直接放大全部分数 | 需要精准瞄准，MISS 会断门链 |
| 连续命中门 | 门链每层 +0.5x | 任何一排 MISS 都会断链 |

实测对比：

```
直线投掷：29/30 钉，1,131 分
分裂 + 完美门 + 倍率：16 钉，2,443 分
```

> 清屏多 ≠ 分高。想冲 6,000 / 10,000，必须规划门链、倍率和停球。

## 7. 爽感设计

| 手法 | 实现 |
|---|---|
| 成长可见 | 壶变大、发光、镜头轻震 |
| 分裂爆发 | 连续“啪啪”分裂 + 粒子 + 拖尾 |
| 连锁清屏 | 30 钉菱形阵，一钉触发两代连锁，分数与音阶一起升级 |
| 速度线 | 高速滑行时壶后出现速度线，减少“等壶停”的焦躁 |
| 命中停顿 | 分裂/清屏/大爆发时 30~50ms hit-stop |
| 大爆发 | 单壶 15 钉触发慢动作 + 金闪 + “大爆发!” |
| 狂潮 | 单壶 25 钉触发更强慢动作 + 蓝闪 + “狂潮!” |
| 音阶 | 连击越高，撞击音越高 |
| 震动 | 门、撞击、分裂、清屏触发不同震动（支持时） |
| 命中停顿 | 大撞击 50ms hit-stop（原型用震屏/慢放替代） |
| 慢动作 | 清屏或大撞击 0.3~0.5s 慢放 |
| 屏幕震动 | 按撞击强度分级 |
| 数字飞溅 | `+10`、`×3`、`COMBO` |
| 音效音阶 | 连击越高，撞击音越高 |
| 结算演出 | 分数滚动、最高分刷新、三星 |

**三条硬规则：**

1. 每 3 秒必须有一次正反馈
2. 每次投掷至少有一个峰值时刻
3. 结束时必须是高光收尾

## 8. 模式

| 模式 | 内容 | 作用 |
|---|---|---|
| 闯关 | 40 关，固定门序 + 目标分 | 教学、留存 |
| 无尽 | 随机门序，3 壶冲高分 | 复玩、传播 |
| 每日 | 固定种子，3 次机会 | 日活 |
| 好友挑战 | 同种子比分 | 裂变 |
| 异步 PvP | 同种子竞速（后续） | 长线 |
| Boss 关 | 巨型钉子结构，限时打爆 | 版本高潮 |

### 8.1 爬塔模式（v0.4 MVP）

- 每层一个怪物防御 DEF，3 壶伤害 ≥ DEF 即突破。
- 层间获得 1 颗石头；两颗同级石头合并升级，提升攻击加成。
- 3 选 1 强化：+1 壶 / +10% 攻击 / +1 心。
- 3 心，失败保留 build 重试本层；0 心结束。
- 最高层数本地保存；后续接排行榜。
- 详细数值与调研见 [`TOWER_MODE.md`](TOWER_MODE.md)。

## 9. 成长与变现

- 永久升级：起始体积 +5%、门判定 +5%、连击衰减 -10%
- 皮肤：壶、拖尾、门特效、钉子
- 激励视频：重随门、再来一壶、双倍奖励、皮肤试用
- 插屏：每局结束，间隔 ≥90 秒
- Banner：主页
- 内购后置，需要版号

**「重随门」是最自然的广告点。**

## 10. 抖音传播

- 15 秒高光录屏：吃门 → 变大 → 分裂 → 清屏
- 同种子比分挑战：“这局你能打多少分？”
- 好友残局分享
- 排行榜 / 侧边栏复访
- 话题：#冰壶大作战 #一壶清台 #分裂冰壶

## 11. 风险

| 风险 | 对策 |
|---|---|
| 数值爆炸、卡顿 | 壶上限 12、半径上限 3x、倍率上限 20x |
| 变成“看动画” | 门要靠瞄准打中；窄门高收益；擦冰微调 |
| 爽但没挑战 | 目标分、减益门、障碍、连击衰减 |
| 门看不懂 | 图标 + 颜色 + 数字；首次慢动作教学 |
| 冰壶味没了 | 保留冰面、大本营、擦冰、旋球 |
| 广告劝退 | 只做可选激励视频；前 3 局无广告 |
| 内容不足 | AI 生成关卡 + 模拟器验证 + 每日种子 |
